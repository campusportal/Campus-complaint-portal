# Campus Complaint Portal

## Project Description
The Campus Complaint Portal is a web application that allows students to submit complaints related to campus issues. It helps the administration manage and resolve complaints efficiently.

## Features
- Student complaint registration
- Complaint tracking
- Admin dashboard
- Secure login
- User-friendly interface

## Technologies Used
- HTML

## How to Use
1. Open the website.
2. Register or log in.
3. Submit a complaint.
4. Track the complaint status.

## Future Enhancements
- Email notifications
- Mobile application
- AI-based complaint categorization
